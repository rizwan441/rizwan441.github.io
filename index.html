Monitoring that notices when a container dies

cAdvisor drops a container's metrics the moment it stops, so crashed containers simply vanished from dashboards. I wrote a last_over_time + container_last_seen PromQL pattern that keeps them visible and alerting.

The firewall that kept dropping production

Nodes kept losing network at random. The cause: a UFW sync agent stuck in an infinite loop, re-applying rules and cutting connections each time.

I stabilized production first, then rebuilt the agent around diff-based, idempotent reconciliation. It now only changes what actually differs. Also moved latency-sensitive telecom services to Docker Macvlan to remove a bridge-NAT bottleneck.
