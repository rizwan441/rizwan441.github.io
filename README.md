# rizwan441.github.io

Personal portfolio of **Rizwan Zafar**, DevOps & Platform Engineer.

**Live:** https://rizwan441.github.io

## What's inside

A single, dependency-free `index.html`: hand-written HTML, CSS and vanilla JavaScript. No framework, no build step.

- Light and dark themes with a remembered preference
- Command menu (`Ctrl/⌘ + K`) for keyboard navigation
- Animated architecture diagram (SVG) for the DID lookup platform
- Interactive canary-release simulation with health gates and automatic rollback
- Responsive down to 360px, respects `prefers-reduced-motion`

## Deploy

Served by GitHub Pages from the `main` branch root. Push to `main` and the site updates in about a minute.

```bash
git clone https://github.com/rizwan441/rizwan441.github.io.git
cd rizwan441.github.io
# edit index.html
git commit -am "Update portfolio" && git push
```
